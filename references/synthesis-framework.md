# Synthesis Framework — 跨期综合（把笔记变成认知档案）

## 输入

- `index.json`：只取统计字段（总数 / 时间范围 / 系列 / 播放分布 / 充电数量），**不要把全部 description 读进来**。
- `notes/*.md`：每期一份（≤600 token）。20 期 ≈ 1.2 万 token，可直接读。
- 需要核对原文时：`show_content.py --bvid ... --part N` 只抽查 1-2 处。

## 分析步骤

1. **归类**：把各期按主题/类型聚类（宏观、国际、行业、方法论、问答）。
2. **抽 thesis**：合并同义论点 → thesis 列表；统计出现频次与时间，标记"强化 / 弱化 / 反转"。
3. **提炼思维操作系统**：
   - 世界观：周期观、结构观、分配观、人性假设
   - 分析范式：从哪一层切入（宏观→行业→个体？）、常用因果链
   - 决策原则：何时进攻/防守、风险偏好、能力边界观
   - 信息与论据偏好：官方数据 / 外媒 / 历史类比 / 个人经验 / 微观体感
4. **观点演变**：按时间线找立场变化（出现 ≥2 次的趋势才算）。
5. **预测账本**：汇总所有可证伪预测；对照后续期数/现实标注状态（待验证 / 已验证 / 未中 / 无法判断）。
6. **认知盲区与偏差**：长期偏好、忽略的反面证据、选择性引用、过度自信点。
7. **表达风格与金句**：常用比喻、口头禅、叙事结构（先抛结论→举例→反问→升华？）。
8. **学习转化**：把方法转成用户可复用的清单/练习（这是"学习其人"的落点）。

## Token 纪律

- 只读 notes，不读 raw；核对原文最多抽查 2-3 处。
- 输出报告控制在 4000 字内，避免把笔记内容原样堆进报告。
- 报告与清单要能被下一次增量分析直接复用（保留"样本清单"与"生成时间"）。
