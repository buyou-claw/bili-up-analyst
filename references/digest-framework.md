# Digest Framework — 单期视频「原味精编」

目标：**不是全文复述，也不是极简结论**，而是保留原视频的叙事顺序、关键原话、例子、比喻、数字与语气，压缩到原文的 30%–45%（约 3000–4500 汉字，硬上限 4500），让读者像"看了一遍精华版"。

## 写作原则

1. **顺序跟随原视频**：开场 → 分论点 → 案例/转折 → 结论；不要按主题重排。
2. **保留原话**：关键判断、比喻、反问、金句用「」或引用块直接引用（带时间点）；其余用自己的话紧贴原意，**不添加作者没说的内容**。
3. **保留"血肉"**：例子、数据、人物、历史类比、具体场景都要留下；删掉寒暄、重复、口头禅、无关闲笔。
4. **只做忠实精编，不评判、不站队**：分析、评价留给 `notes/` 和 `report.md`。
5. **标注不确定**：ASR/字幕转写可疑处加 `(?)`，不要补写、不要编造。
6. **可独立阅读**：没看过原视频的人也能读懂"他讲了什么、怎么讲的"。

## 结构与长度（约 3000–4500 汉字）

```markdown
# <视频标题>
> 日期 | 时长 | BV | 来源（subtitle / asr）

## 本期一句话
（≤50 字，用原话或紧贴原意）

## 内容精编

### 1. <小标题>（mm:ss）
（200–500 字：这一段讲了什么、怎么论证、原话引用 1–2 处、关键数字/例子）

### 2. <小标题>（mm:ss）
...

（按视频顺序分 4–8 段；小标题可用原话关键词，如"穿皮衣买机票""上秤"）

## 关键数据
| 指标 | 数值 | 来源/时间点 |
|---|---|---|

## 结论与预测（原话为主）
- 「……」——他给出的判断/预测，尽量保留原句

## 金句原文
> "……"（mm:ss）
（3–6 条）
```

## 压缩率自检

- [ ] 精编字数 / 原文字数 ≈ **30%–45%**（汉字数 3000–4500，**不超过 4500**）
- [ ] 至少有 **3 处直接引用**（原话/比喻/反问）
- [ ] 保留了原视频的**顺序**（不是主题重排）
- [ ] 例子、数字、人物、历史类比没有丢
- [ ] 没有加入作者没说过的话
- [ ] 没看过原视频的人能独立读懂
