# Digest Framework — 单期视频「原味精编」

目标：**不是全文复述，也不是极简结论**，而是保留原视频的叙事顺序、关键原话、例子、比喻、数字与语气，压缩到原文的 30%–45%（约 3000–4500 汉字，硬上限 4500），让读者像"看了一遍精华版"。

## 视角与指代（硬规则）

- **以 UP 主为叙述主体，用第一人称复述**（"我认为""在我看来"可省略主语，直接陈述观点）——读者看到的应该是"UP 主在讲什么"。
- **被讨论的对象一律直呼其名/角色**（黄仁勋、特朗普、沃什、美联储、德国、日本、以色列……），**绝不用"他"指代**。
- 需要指代 UP 主本人时：用"UP 主"或省略主语，**不要**用"他"。
- 引用原话时引号内照抄原文（原文里的"他"没问题），**引号外**必须遵守上述指代规则。
- 示例：
  - ❌ "他说黄仁勋这套方案很原始……他缺乏应用环境"（两个"他"指不同人）
  - ✅ "黄仁勋这套数字孪生方案『其实挺原始的』……黄仁勋缺乏把虚拟成果应用的环境"（UP 主视角、主语清晰）
  - ✅ "在 UP 主看来，黄仁勋这套方案……"（第三人称但指代明确）

## 写作原则

1. **顺序跟随原视频**：开场 → 分论点 → 案例/转折 → 结论；不要按主题重排。
2. **保留原话**：关键判断、比喻、反问、金句用「」或引用块直接引用（带时间点）；其余用自己的话紧贴原意，**不添加作者没说的内容**。
3. **保留"血肉"**：例子、数据、人物、历史类比、具体场景都要留下；删掉寒暄、重复、口头禅、无关闲笔。
4. **只做忠实精编，不评判、不站队**：分析、评价留给 `notes/` 和 `report.md`。
5. **标注不确定**：ASR/字幕转写可疑处加 `(?)`，不要补写、不要编造。
6. **可独立阅读**：没看过原视频的人也能读懂"他讲了什么、怎么讲的"。

```markdown

> 日期 | 时长 | BV | 来源（subtitle / asr）

## 本期一句话
（≤50 字，用原话或紧贴原意）

## 内容精编

### 1. <小标题>（mm:ss）
（200–500 字：这一段讲了什么、怎么论证、原话引用 1–2 处、关键数字/例子；用 UP 主视角叙述）

### 2. <小标题>（mm:ss）
...

（按视频顺序分 4–8 段；小标题可用原话关键词，如"穿皮衣买机票""上秤"）

## 关键数据
| 指标 | 数值 | 来源/时间点 |
|---|---|---|

## 结论与预测（原话为主）
- 「……」——他给出的判断/预测，尽量保留原句

## 金句原文
> "……"（mm:ss）
（3–6 条）
```

## 压缩率自检

- [ ] 精编字数 / 原文字数 ≈ **30%–45%**（汉字数 3000–4500，**不超过 4500**）
- [ ] 至少有 **3 处直接引用**（原话/比喻/反问）
- [ ] 保留了原视频的**顺序**（不是主题重排）
- [ ] 例子、数字、人物、历史类比没有丢
- [ ] 没有加入作者没说过的话
- [ ] 没看过原视频的人能独立读懂
