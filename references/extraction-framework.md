# Extraction Framework — 单期视频的"认知/思维"提取

## 角色与纪律

你只处理**一个视频**。目标：把内容压缩成一份可供跨期综合的"认知笔记"。

- 只读 `show_content.py` 输出的本期内容；不读其他期、不做跨期总结。
- 输出一份 `notes/<日期>_<标题>.md`，总长 ≤ 800 汉字（约 600 token）。
- 本文件产出的是**短笔记（给综合用）**；同一次任务还要按 `digest-framework.md` 写一份给人读的「原味精编」到 `DIGEST_FILE`。
- 精编完成后，`scripts/append_digest_excerpt.py` 会把精编的节选作为**最后一段**（`## 内容精编（补充）`）追加到本笔记；原 9 节保持不变，属预期结构。
- 保留可验证信息（数据、时间、出处）；ASR 转写的可疑词加 `(?)`。
- 不做全文复述，只提取"体现其认知与思维"的部分。

## 提取维度（对应笔记固定章节）

1. **一句话结论**：这期视频的核心判断（≤40 字）。
2. **核心论点与证据**：2-4 条，每条"论点 → 论据/数据 → 出处/来源"。
3. **关键数据**：数字 + 指标 + 来源，最多 6 条。
4. **推理链条**：他如何从 A 推到 B（1-3 步，用箭头表示）。
5. **思维模型 / 框架 / 比喻**：用来解释世界的框架、类比、经验法则。
6. **可证伪预测**：带时间窗的明确预测（无则写"无"）。
7. **立场与盲区**：对关键主体（美国/欧洲/日本/房地产/AI/政策/市场）的立场；可能的偏差或未讨论的反面证据。
8. **金句**：2-4 条**原文**引用（尽量带时间点）。
9. **类型与来源**：视频类型（宏观解读/事件评论/方法论/问答/其他）、内容来源（subtitle/asr/ai/none）。

## 质量要求

- **可累积**：后续综合只依赖这些笔记，因此每条论点要能独立读懂。
- **去水**：删掉寒暄、重复、口头禅；保留判断句与论据。
- **区分事实与观点**：数据=事实，解读=观点，不要混写。
- **标注不确定**：ASR/字幕转写可能有误，存疑名词加 `(?)`，不要编造。
